# Third-party notices

## Attribution policy

AI generation does not replace or diminish upstream authorship. This
repository uses the following rules:

- Derivatives retain the upstream copyright, license conditions, disclaimer,
  and author credits in the distributed source.
- Independently implemented tools identify inspected or inspirational
  projects without claiming that their authors endorsed this work.
- Projects without a clear redistribution grant are referenced or patched;
  their complete source is not republished here.
- External programs, services, exports, and local data sources are credited
  as dependencies but are not presented as part of this repository.

There is no repository-wide blanket license. The notice or license within each
project governs that project's files.

## AutoWS / AutoWS2

`addons/AutoWS2/` is a clean implementation inspired by AutoWS 0.3.1 by
**Lorand**. Lorand remains the author of the original AutoWS concept and
addon:

<https://github.com/lorand-ffxi/addons/tree/master/AutoWS>

The original repository does not advertise a repository-level license through
GitHub. AutoWS2 therefore does not redistribute AutoWS source or `lor_libs`.
Its independently written source is distributed under the BSD-style notice at
the top of `AutoWS2.lua`.

## Roller / Roller2

original header credits Balloon and Lorand and contains a BSD-style

<https://github.com/Selindrile/Roller>

## SendAllTarget / PartyCombat

Selindrile's SendAllTarget (SAT) demonstrated packet-level target coordination
for Windower multiboxing and credits **Arcon** for code used by SAT:

<https://github.com/Selindrile/SendAllTarget>

`addons/PartyCombat/` is an independent implementation with action-driven

## Selindrile GearSwap, Motenten, and PartyStart

PartyStart's optional BRD, RDM, and WHM controllers are original integration
files designed for the callback and override model in **Selindrile's GearSwap
framework**:

<https://github.com/Selindrile/GearSwap>

Selindrile's shared include states that much of that framework was adapted
from **Motenten's** base files. PartyStart does not redistribute Selindrile's
or Motenten's GearSwap files. Users supply their own compatible GearSwap
installation.

PartyStart sends documented commands to Roller2 and HealBot but does not
bundle either addon.
