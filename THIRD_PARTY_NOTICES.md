# Third-party notices

## AutoWS / AutoWS2

`addons/AutoWS2/` is a clean implementation inspired by AutoWS 0.3.1 by
**Lorand**. Lorand remains the author of the original AutoWS concept and
addon. AutoWS2 does not redistribute the original source and does not require
`lor_libs`. Its source and README retain explicit attribution and a BSD-style
license notice.

## Roller / Roller2

`addons/Roller2/Roller2.lua` is derived from Roller 1.8 by Selindrile. The
original header credits Balloon and Lorand and contains a BSD-style
redistribution license. That header is retained verbatim at the beginning of
the derived source and governs the inherited code.

Roller2-specific changes were generated by OpenAI Codex at the direction of the
repository owner. The README describes the behavioral differences.
