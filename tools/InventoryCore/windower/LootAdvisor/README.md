# LootAdvisor

LootAdvisor is the read-only Windower frontend for InventoryCore. It watches the
treasure pool and prints an English recommendation for every newly observed
item.

## Requirements

- Windower 4
- InventoryCore configured and running at `http://127.0.0.1:8787`
- A generated `data\recommendations.lua` cache for fast owned-item lookup

Copy this complete folder into `Windower\addons\LootAdvisor`, then load it:

```text
//lua load LootAdvisor
```

## Commands

```text
//la pool
//la item <exact English item name>
//la reload
```

- `pool` reprints recommendations for the current treasure pool.
- `item` requests one exact Windower resource name.
- `reload` reloads InventoryCore's generated owned-item cache.

## Recommendation behavior

- Owned items use the generated local cache.
- New or unowned items query InventoryCore's localhost endpoint.
- A first-time market lookup still returns item/category/vendor guidance and
  queues Valefor pricing in the background.
- Repeat `//la pool` after a few seconds to pick up a completed market query.
- Output uses ASCII-only punctuation for FFXI chat compatibility.

LootAdvisor never lots, passes, sells, sends, or drops items.

If output says `LOOKUP FAILED`, confirm InventoryCore is running and that
`http://127.0.0.1:8787` opens locally.
