# Performance tools

Collector and analyzer source is included.  Personal session captures,
process/window-title records and operational incident reports are excluded.
Keep generated captures local.

The frame collector requires a separately supplied PresentMon executable.
Use its `-PresentMonPath` parameter to select your installation.  This
repository does not bundle or claim ownership of PresentMon.

The capture command observes running game processes.  It is separate from
the offline addon test suite and is not run by test setup.
