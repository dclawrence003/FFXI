# Leshonn B — first non-REMA proof

Primary sources: the local BG Wiki mirror and Umbra's `Sortie - Melee Comp`
workbook sheet. Shard B is mandatory. Metal B mitigates thunder-hand Stun and
wind-hand Weight, while the core hazards remain Zap debuff copying, Chokehold
buff theft, and healing from matching Wind/Lightning damage.

Version 1.1 deliberately uses the party's verified Naegling/Maxentius/Tauret
loadouts. Savage Blade and Black Halo do not skillchain with one another.
Kickpuncher's automatic WS is held because an opportunistic closer can create
Wind/Lightning-aligned damage.

The safe policy is deliberately form-agnostic. BRD uses the reviewed
zero-debuff `magicboss` preset, RDM uses zero-debuff `sortieacuex`, and PLD uses
`manualsc` with native buff/tank automation disabled. That prevents automated
Elegy, Dia, Flash, and Sentinel while retaining GEO Fury/Frailty and DNC Box
Step. Manual actions remain available.

Only Tackleberry stands in front because Leshonn's counters can exceed 500
damage. The other five belong behind or on a rear flank. This positioning is
an operator instruction, not a software gate.
