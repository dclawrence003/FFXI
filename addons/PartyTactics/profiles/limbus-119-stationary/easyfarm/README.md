# Limbus 119 EasyFarm artifact

Load `Tackleberry-Limbus-119-Stationary.eup` manually in EasyFarm before
arming the Limbus profile. It is intentionally separate from the Locus and XP
camp artifacts.

- Its target allowlist is limited to the reviewed Om' and Apollyon enemies
  used by the current route.
- The whole-word `Elemental` ignore rule remains enabled.
- Detection is 18 yalms and the Flash action boundary is 20 yalms.
- Approach is Off and engagement is On, preserving the planted puller.

PartyTactics does not load, start, or rewrite EasyFarm. If another Limbus
route requires different enemies, copy this artifact to a new descriptive
filename and review that target list instead of broadening a file shared with
another fight.
