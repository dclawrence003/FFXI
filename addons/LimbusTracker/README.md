# LimbusTracker

LimbusTracker is a lightweight, read-only Windower 4 display for the Limbus
history maintained by InventoryCore. It does not inspect interaction packets,
request currencies, or write chest events itself. LootAdvisor remains the one
telemetry collector, which prevents duplicate tracking and extra packet work.

## Requirements

- Windower 4
- InventoryCore running at `http://127.0.0.1:8787`
- LootAdvisor loaded on each character whose openings should be recorded

Copy the complete folder to `Windower\addons\LimbusTracker` and load it:

```text
//lua load LimbusTracker
```

The default `limbus` mode automatically shows the panel in Temenos or
Apollyon and hides it everywhere else. Settings and display coordinates are
stored separately for each character.

## Display

The default self view shows:

- the least recently opened sector as `Next` once all four are learned;
- the most recently confirmed 5,000-unit chest as `Bonus`;
- the five latest openings, newest first;
- `5*` for a 5,000-unit opening and `3` for a 3,000-unit opening.

Example:

```text
LimbusTracker [Dolomedes]
Temenos  Next: West  Bonus: Central
  Recent: North:3 > Central:5* > East:3 > West:3 > North:3
Apollyon  Next: NE  Bonus: SW
  Recent: NW:3 > SW:5* > SE:3 > NE:3 > NW:3
```

`Next` is a rotation recommendation, not a prediction of the next bonus. The
game can choose the same 5,000-unit bonus chest again.

## Commands

```text
//lt refresh
//lt status
//lt toggle
//lt mode limbus
//lt mode always
//lt mode off
//lt view self
//lt view roster
//lt pos <x> <y>
```

- `limbus` shows the panel only inside Temenos or Apollyon.
- `always` keeps it visible everywhere.
- `off` hides it while leaving the addon loaded.
- `self` shows full history for the local character.
- `roster` shows each configured character's next Temenos and Apollyon sector.

The display polls the localhost dashboard every five seconds. It does not
contact any remote service.
